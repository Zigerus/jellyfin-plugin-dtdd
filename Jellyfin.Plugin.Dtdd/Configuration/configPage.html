DoesTheDogDie

Surfaces a per-user Safe / Not Safe badge on Jellyfin item detail pages, driven by DoesTheDogDie.com data. Each Jellyfin user configures their own phobia list from the badge gear icon.

Required companion plugin: JavaScript Injector — without it, the backend still serves data but the UI badge will not render. Install it, then restart Jellyfin once.

Get one at doesthedogdie.com/account (free account → request API access). The key is sent in the X-API-KEY header on every outbound request and is never logged or echoed elsewhere.
How long to keep cached DTDD responses before refetching. Default 14. Lower values mean fresher data but more API hits.
When on, a weekly task scans your Movies and Series library and prefetches missing DTDD warnings into the cache. Default OFF — politer to DTDD's API until you trust cache stability. Triggers, schedule, and per-run logs are visible at Dashboard → Scheduled Tasks → "Prefetch DoesTheDogDie warnings".
Advanced. Leave at the default unless DTDD moves to a different host or you are routing through a proxy.
